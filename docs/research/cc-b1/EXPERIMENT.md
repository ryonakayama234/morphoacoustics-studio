## Split acceptance — stop goal-post inflation (2026-10-21)
**Current evidence:** original section0 listener report "cannot tell a difference", then another informal unblinded report that `s04_110.wav` sounds slightly different, possibly lower. These are observations not a formal ABX. Core source F0=100Hz was unchanged; at end-of-task the Core resonance peaks are `base R1/R2=275/2101.75Hz`, `s04_110=273.75/2132Hz`. Independent Wolfram reconstruction of the **actual approximate resistively loaded end-state output transfer** predicts opposite changes across nearby harmonics, −4.448dB at 2100Hz and +3.047dB at 2200Hz, a plausible timbre cue but not measured whole-WAV output or evidence of pitch drop. Site4 already moved (~4.640627× rest cross-section under preexisting terminal Gesture), so this is a different **rest body**, not a newly enabled performance motion.
