## 固定前提（議論の対象外として渡す）

1. **等価身体**: 逆路線の出力は「元の話者の解剖」ではなく、(a) 目標の声の知覚的な核を再現でき、(b) BODYMAP のモジュールに分解できて編集でき、(c) パラメータを動かすと音が予測可能に変わる身体。身体には来歴（推定元音声、INFERRED であること）を付ける。
2. **身体と運動を混ぜない**: 音声には身体（素質）と運動／演技が混ざっている。身体パラメータは複数発話に共通として扱い、演技を解剖に焼き込まない。1ファイルだけの場合は「身体＋その演技」の束として主張を弱める。
3. **測定の規律**: 判定は測定科学で行い、聴感は最終の二値採用のみ。G0 特徴量 method は全て DEFINED_NOT_VALIDATED のままなので、合否判定には B2 と同じく**直接観測量**（複素伝達・スペクトル包絡・ピーク等の生量）を使い、特徴量は探索的記録に留める。
4. **B2 の現在地**: 受動損失（LRF）は登録範囲内で実装適合 PASS・効果検出済みで限定採用された（Core PR #298 マージ済み）。ただし「音から損失を同定できるか」は別の問いであり、B2 の主張と混ぜない。
5. **ニューラルの置き場**: 物理パラメータ空間の中での推定・探索・残差に限る。波形を直接真似る声クローンは対象外。
6. **最初の素材候補**: RJ01745881 Track 3（CV 御子柴泉）。測定には SE なし版（WAV 48kHz/24bit）を使う前提。音源は個人の研究用にローカルで扱い、再配布しない。
7. **現行 Core の現実**: 本番は Fidelity 0（静的・1次元・剛壁・無損失の直列声道、インピーダンスを返す）。音源は prescribed LF flow、F0=100Hz 固定。CC-A2 が M0/M1＋OD-2 家族の身体を prescribed performance でレンダリングする。設計はこの現実の内側で組むこと（無い能力を前提にしない）。

## 質問

### QR1 全体設計（段0＋段1 の成果物の形）
段0（測定のみ）と段1（合成ラウンドトリップ）の成果物として何を凍結すべきか。特に:
- 等価身体の表現形式: BODYMAP の Body Assembly／モジュール語彙のどこに落ちるか。現行の `core_body_revision`（B1、M0 由来 OD-2 家族）との関係（段1 の等価身体はまず研究側の表現でよいか、Character の下書きとして扱う条件は何か）。
- 来歴と主張ラベルの形式: INFERRED の明示、推定元・手法・版の記録項目。
- 段の完了条件と、段2（実在音声フィット）へ進むゲートの形。

### QR2 合成ラウンドトリップの実験設計（本丸）
正解が分かる合成で、モジュール別の同定可能性を測る実験の処方:
- **順方向の経路**: 前提7の現実で「目標音／目標観測量」をどう作るか。CC-A2 のレンダリング出力（WAV）を使うか、伝達関数レベルの観測量で閉じるか、その両方か。F0=100Hz 固定・prescribed source の制約の下で、source 側の何を「身体の素質」として可変にできるか（できないなら、その旨を同定可能性台帳の結論として先に書く形か）。
- **フィット対象**: tract のパラメータ化（16区間の断面積そのもの／OD-2 家族のような低次元パラメータ化／その中間）、初期値と探索範囲、拘束条件。
- **目的関数**: 直接観測量ベースの距離の定義（どの周波数帯・どの量で比べるか）。知覚的な核と測定量の対応づけの主張の置き方。
- **最適化**: 手法の候補（勾配が使える形か、微分可能でない現行経路では何を使うか）、複数初期値と非一意の扱い、計算予算の目安。
- **物差し**: モジュール別に「パラメータ空間で正解に近いか」と「観測空間で音が合うか」を分けて測る方法。非一意（音は合うが身体は違う）の台帳化の形式。hold-out（フィットに使わない発話／条件での再現）の置き方。
- 事前登録として固定すべき点の列挙（B2 の FZ 項目に相当するもの）。

### QR3 段0 の設計（実在音声の測定のみ）

- 特徴量 method 未検証の問題の扱い: 段0 と並行して method 検証（合成 fixture）を兼ねる設計か、段0 は直接観測量と生波形統計のみで閉じるか。
- 行動アノテーション（発話／呼吸／接触／Scene の4層）の最小仕様: ラベルの粒度、point と span の使い分け、半自動化（無音検出・左右バランス等）の範囲、Owner の手作業負荷の上限の置き方。
