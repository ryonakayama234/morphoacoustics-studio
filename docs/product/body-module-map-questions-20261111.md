# 質問票 BODYMAP-20261111-01 — 身体モジュール地図の設計

**宛先**: Research Lead（ChatGPT）／ **審査**: 監督者（Muse）／ **決定**: Owner（中山）
**追跡**: Studio Issue #56 ／ **回答コード**: BODYMAP-R-20261111-01（docs-only の Draft PR で回答）
**範囲**: 設計の処方のみ。実装・採用・マージ・既存の関門（B1 等）の変更は含まない。

## 前提（Owner の方向づけ、2026-11-11）

1. 製品の軸は声ではなく**身体**。声に関連する身体モジュールを分解し、好みの身体を組み立てられる創作アプリにする。
2. 声はその身体の発展系。身体モジュールだけではまともな声にできない分は、**最後にニューラル**で補う（物理的因果を壊さない継ぎ目で）。
3. 身体は**人間でなくてよい**。異種・人ならざるモノの身体も対象であり、パラメータ範囲を人間の解剖に固定しない。
4. 従来の制約は維持する: 物理的因果の捏造・恣意的な音声加工は禁止。判定は測定と物理のゲート優先。主張は証拠の射程内に限る。

## 質問

### QM1 — モジュールの分解
声に関連する身体を、組み立て可能なモジュールへどう分解するか。候補（気流源／声門・音源／声道／調音（舌・唇・顎）／側枝（鼻腔等）／放射・境界／聴き手）に対して、各モジュールの物理的役割、入出力ポート、パラメータ、状態を定義してほしい。OMA 語彙 v0 との関係（拡張か、別層か）も明示すること。抜けているモジュール、二重になっている分解があれば指摘してほしい。

### QM2 — パラメータ範囲と「人でない身体」
各モジュールのパラメータ範囲を人間の解剖に固定しない設計にするとき、範囲の決め方（物理モデルが意味を持つ範囲、数値が安定する範囲、主張可能な範囲の区別）と、「種の違い」をパラメータで表す部分と構造の違いとして表す部分の線引きを処方してほしい。例: 声道が極端に長い／短い、音源が2つある、唇がない、呼吸器が人間と違う、等。

### QM3 — 組み合わせの規則と同一性
モジュール同士の接続規則（何と何がつながるか、ポートの型と単位）、物理的に矛盾する組み合わせ・現行モデルでは扱えない組み合わせの扱い（UNMODELED としての明示か、拒否か）、組み立てた身体の同一性と版管理（B1 の `core_body_revision` との関係、再導出可能性）を処方してほしい。

### QM4 — 既存資産との対応
QM1 の各モジュールについて、現状を「製品で使える／研究のみ／未実装」の3区分で対応づけ、地図の空白（特に製品化の障害になる空白）を列挙してほしい。B1 の OD-2 カタログは地図のどこに位置するかも明示すること。

### QM5 — 地図の上での進み方
この地図の上で、B2・B3、声質の5要因分離、SMC の接続、聴き手側（EL／ASMR）の段階的採用、ニューラルの継ぎ目が、それぞれどのモジュールの話になるかを示し、推奨する順序と各段の関門（何が検証できたら次へ進めるか）を処方してほしい。順序は「身体→声→ニューラル最後」の方向づけと矛盾しないこと。
