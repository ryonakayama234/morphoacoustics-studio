## 1. Normative semantics

The proposed **take-metrology-pack/0** is independent of **studio-v0-take-envelope/v0**. It addresses an existing evidence object but never modifies the Take, receipt, BagIt archive, manifest, or original run. **Mandatory** means each field has a recorded value *or an explicit coverage state and reason*, not that every physical quantity has been observed. Each claim is tagged **[F]** (bounded previously reported fact), **[H]** (prospective contract/design), or **[U]** (unknown/unvalidated). Run-time attestation, post-hoc calculation, display audio, perception and physical modeling are separate evidentiary layers.

Identities **Body, Character, Motor/Performance, Source, Boundary, Observer, Take** MUST remain distinct. A Core-authored OD-2 revision is not minted by Studio; a preview gain is not vocal effort; the fixed LF100 prescribed input is not measured phonation or speaker identity. The owner of any numeric claim must provide the unmodified source anchor, pin, unit, observation plane, measurement/calculation method, provenance and coverage record.

## 3. Units, reference plane and prohibited labels

1. The present Studio M0/M1 envelope [F] uses Core pin **b569f044bfda309dff1a00cccf8365754e6b1355**, prescribed LF **100 Hz**, fixed “あい”/3-task, seed 0, **48,000 Hz × 24,000 frames = 0.5 s**, with model **0.20 m pressure proxy**; M0 has sixteen 0.010 m sections and M1 sixteen 0.011 m sections. [QG1](body-map-g0-response-20261111.md), [S5](https://github.com/ryonakayama234/morphoacoustics-studio/issues/50#issuecomment-6736075443).
2. **raw pressure level** uses non-demeaned RMS: p_rms = sqrt(sum(p[n]^2)/N) [Pa]; explicitly save mean [Pa] and absolute peak [Pa]. If p_rms > 0 and finite, proxy_db_re_1pa = 20 log10(p_rms / 1 Pa); label **“dB re 1 Pa (model proxy)”** only. For zero RMS, linear 0 Pa remains valid but logarithmic level is null with ZERO_RMS; for empty/non-finite samples both quantities are invalid with reason.
3. The **0.20 m proxy is not a calibrated free-field/ear/microphone sound pressure** even when numeric values are in Pa. Calling it “dB SPL”, “absolute SPL” or an ear-level measurement with a 20 µPa reference is **prohibited until a separate calibrated observation contract is adopted**. A different load, reference plane, sign, port or medium invalidates unqualified comparisons.
4. Preview WAVs are per-Take peak-normalized; their gain, PCM clipping or arbitrary playback_gain_db are downstream observation/display operations. They MUST be recorded separately from model raw Pa and physiological vocal effort (currently UNMODELED).
5. Complex transfer features are comparable only with the same source/load/port pair, frequency grid, sign convention and reference plane. A source-free ideal-pressure-release calculation cannot be silently equated with a loaded physical response.

## 5. Failure, absence and numerical rules

**Coverage is field-local; never substitute numeric 0, an inferred organ state or a guessed SHA for unknown data.** MEASURED means values were reported as measured in original evidence; a second-level qualifier REPORTED_ONLY/BYTES_VERIFIED/REEXECUTED records verification by the present reviewer. RECOMPUTABLE requires verified original bytes, the fixed method, exact units and plane; computation later produces a **new** DERIVED_RECOMPUTED record, not a historical MEASURED value. NOT_APPLICABLE requires a specific physical reason, such as a refusal with no audio; UNMODELED is a reason, not a measurement of zero.

**Reason vocabulary:** NOT_CAPTURED; ARTIFACT_UNAVAILABLE; RAW_BYTES_UNVERIFIED; SOURCE_NOT_ATTESTED; UNMODELED; UNCALIBRATED; METHOD_UNFROZEN; METHOD_INVALID; INVALID_NUMERIC; EMPTY_SIGNAL; ZERO_RMS; LOW_PERIODICITY; PIN_MISMATCH; PLANE_MISMATCH; REFUSAL_NO_AUDIO; NOT_IDENTIFIABLE; ORIGIN_NOT_PRODUCT_TAKE. Store the originating refusal code separately. Any missing known coefficient, solver divergence, non-finite audio, inconsistent artifact hash, mismatched Core pin or forged receipt MUST yield STOP/UNKNOWN or a typed refusal—not a fallback success waveform.

## 6. Versioning, compatibility and freeze authority

- **pack_schema_version = take-metrology-pack/0**; **feature_set_id = bodymap-take-features/0**. Each derived feature is bound to **feature_algorithm_id**, immutable parameter manifest digest, method source commit, dependency/lock digest, input raw bytes SHA and scope, window/index selection, observation plane, derivation environment/time, reason for invalid/null, and reviewer.
- **Compatible:** additive optional field with explicit default-absent interpretation, documented as v0.x, and proven old-reader compatibility. Missing fields are NOT silently assumed. **Incompatible:** renaming or changing physical meaning, units, reference plane, evidence qualification, required cardinality, failure semantics or any feature recipe/threshold → **new pack major and/or feature method ID**.
- Cross-Take result comparison is **SAME_METHOD** only under matching method ID/parameter SHA, physical model/pin, observer/reference plane, load and admissible provenance; alternatively both preserved original raw artifacts can be **recomputed separately with the same newly versioned method** and labeled as two DERIVED_RECOMPUTED records. One-sided method updates are **NOT_COMPARABLE**.
- Submit A + proposed schema/methods (B), retrospective/UNKNOWN ledger (C), prereg/capability table (D). Muse independently reviews units, reference planes, deterministic definitions, null and forged-SHA adversarial cases, and [MQ1–MQ4 decisions](https://github.com/ryonakayama234/morphoacoustics-studio/pull/59#issuecomment-6795436085). **Only Owner** can freeze with **explicit artifact commit SHA, content SHA for each document and method IDs**, recorded separately as outcome E. No auto-freeze on Draft PR submission/CI/merge. An error after freeze is an **append-only amendment event**, never mutation of frozen bytes or retrospective provenance.
