## 0. 固定条件（変える提案はしない）

- 2リポジトリ構成: Core = morphoacoustics（物理法則の権威、headless 研究カーネル）、Studio = morphoacoustics-studio（Character 設計・台本を読ませる・演じる創作の場）。軸は「身体の創造性／構造と運動から物理的に説明できる声／Studio の創作体験（変更→演技→聴き比べ→保存）」の3点。

- 身体軸の方向づけ（2026-11-11 Owner）: 製品の軸は声そのものではなく身体。声に関連する身体モジュールを分解し、好みの身体を組み立てられる創作アプリにする。身体は人間でなくてもよい（人ならざるモノの身体も対象）。モジュールだけでは届かない分は最後にニューラルで補う順序。
- 発話と息: 呼吸と発声は同じ気流・声門を共有する。発話に混じる息は別トラックの重ねではなく、1気流源の振動／乱流の配分と圧の揺らぎ（声門漏れ）として発声の内側に出す形が本来の姿（2026-11-11 Owner 指摘）。近接・呼吸・囁きは後処理でなく身体と Scene の物理から成立させる。

## 1. Owner の達成像（監督者が既存の表明から言語化したもの）

- 最終像: Morpho の身体と物理から生まれた声で、実際に1本の声・ASMR 作品を作って売り、それが繰り返せる（2作目以降や、身体・作品のラインが増える）状態になること。研究はその製品を他と違うものにする土台として育つ。
- 製品の核: 「上手い声だけ」なら既存サービスの後追いで退屈、という Owner の見方がある。差別化は、身体を組み立てると声が物理から出ること、近接・呼吸・囁きが身体と Scene の物理から成立すること、身体が人間でなくてもよいこと。
- 体験の返り方: 節目では数値や文書だけでなく、聴ける音・作れる身体・公開できるサンプル・買える作品という形が Owner と聴き手に返ること。
- お金の位置づけ: 大儲けの約束ではなく、「物理から生まれた声が作品として買われるか」を数字で確かめることが最初の意味。売上は GPU やストレージなど次の資源への接続としても位置づけられる。

## 2. 質問

- **QB1（大目標の定義）**: §1 の最終像を、大目標として 1 文＋「達成したときに Owner が聴けて・売れて・繰り返せる具体物」の形で定義すること。候補を 2〜3 案並べ、各案の trade-off を示すこと。案の軸は少なくとも「作品先行（声・ASMR 作品そのものを売る）／創作道具先行（身体を組むアプリ・素材を売る）／研究エンジン先行（物理の到達を製品とみなす）」の違いを含めること。物理ゲートの数値だけで定義しないこと、逆に売上金額だけで定義しないこと（最初の販売は「買われるかの検証」としての意味も含めて書くこと）。
- **QB2（マイルストーン分解）**: 大目標から逆算したマイルストーンを提案すること。各マイルストーンについて「タイトル（短い名詞句）／達成したと言える聴ける・見える形（音・作品・デモ・成果物）／数値・認定条件がある場合はそれ／依存する下位マイルストーン／その時点で可能になる公開・販売・体験などの出口」を表で示すこと。事前登録や実験の段数だけが並ぶ分解にしないこと。
- **QB3（主幹と分岐）**: 既存の資産と論点を QB2 のマイルストーンへ対応づけ、どれが主幹（順序が固定）で、どれが並行できる分岐かを示すこと。対象は少なくとも: Core 物理（OMA 語彙／G0／G1 E1 対照）、BODYMAP（B1 P2 保留／B2 完了／B3 側枝・源の身体化）、逆路線（段1 凍結・未実施、その先の製作素材化）、声質改善の3層（測定パック／5要因分離／段ごと実装）、SMC 言語運動、ASMR／Embodied Listener、Studio の背骨と凍結契約、SNS 先行の定期公開、1作目の販売（売り場・価格・分量・年齢区分のライン分け）。特に「研究トラックと製品・作品トラックを1本に保つか、分けて合流させるか」「最初に売れる最小の形は作品か、道具か、素材パックか」を正面から扱うこと。各論点を、捨てる／後段／並行のどれに置くか根拠つきで述べること。
- **QB4（目先の仕事の位置づけ）**: 保留中の B1 P2、凍結済みで未実施の逆路線段1、その先の実装計画、未決定の声質改善3層、保留の Core G1 という目先の列が、QB2 のどのマイルストーンのどの部分に当たるかを地図上に置くこと。「あと何段で最初のマイルストーン（聴ける・公開できる形）に届くか」「あと何段で最初の販売に届くか」が Owner に見える形にすること。行き詰まり感の正体（製品・作品がまだ一度も返っていない／物理の関門と手続きが膨らむ／声質を測る物差し自体が無い／Owner の PC と時間が律速 等）への診断もここで述べること。WG2 却下の前例を踏まえ、「音が売り物になる品質か」をどの段で・何で判定するかもここで扱うこと。
- **QB5（サブ目標として登録できる形）**: Goals に実際に登録するサブ目標の候補リストを、5〜8 件に絞って提案すること。各件は「タイトル／1 行の現在地／2〜3 文の説明／完了の定義」がそのまま登録文として使える形で書くこと。20 件の細切れや、逆に大きすぎて終わりが見えない粒度は避けること。少なくとも最初の販売に届くサブ目標が、候補のどこに現れるかを明示すること。
- **QB6（horizon の置き方）**: 日付の約束ではなく、今／次／その次／遠くの 4 層で各マイルストーンを配置し、各層の出口条件（何が聴けたら・何が売れたら次層へ進むか、何が見えたら止めて組み直すか）を反証可能な形で示すこと。資源制約（Owner の PC 時間と聴く時間、ストレージ、無料計算枠、販売の手数料と審査期間）を前提に、層が進むごとに何が律速になるかも述べること。
- **QB7（失敗・転換と進め方）**: この大きな計画全体が失敗する条件、途中で大目標自体を縮小・変更すべきサイン、逆に想定より早く進んだ場合に前倒しすべき分岐を挙げること。あわせて進め方について、物理ゲート・事前登録・凍結という重い手続きを「どの段では維持し、どの段では軽くするか（デモ・作品先行、探索と認定の分離など）」の線引き案を出すこと（Owner の最終採否は別途）。販売に伴うリスク（DLsite の AI 区分・運営確認、制作方法の正直な表示、目標音声を解析する際の権利と再配布しない扱い、成人向けラインと全年齢ラインの分け方）で計画が止まる条件もここで扱うこと。
